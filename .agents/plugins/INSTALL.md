   - If present and exact, run `codex plugin marketplace upgrade cogentstack --json` once.

   Do not use `Invoke-WebRequest`, `curl`, BITS, a raw GitHub download, a temporary installer, or another shell-level downloader.
4. Read the marketplace list once more, resolve the reported `cogentstack` root, and require the exact checked-in file `.agents/plugins/install-cogentspec.ps1` beneath that root. Do not search anywhere else or copy the file.

Never substitute an older package, `/activate`, localhost, an embedded-panel login, or another installation route.
