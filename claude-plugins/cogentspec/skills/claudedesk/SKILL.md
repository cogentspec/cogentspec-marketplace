# ClaudeDesk: quiet one-shot startup

The host substitutes the current session ID in this skill. An unexpanded or missing ID is a bounded failure; never invent one, use a Codex thread ID, or read chat history to find another session.

ClaudeDesk does not require **Initiate Bridge**, a listening tab or an ownership transfer. Its dedicated version-1 launcher supervises one update check, isolated project resolution, account/device verification, and its own session-bound worker. Its runtime, readiness files and mutex are separate from Web, Snap, Local and GPTDesk. Do not run their commands, the generic connection sequence or a global runtime reset. Shared account checks, protected credentials and approved project-action primitives keep their existing authorization gates.
