# Connect a copied CogentSpec Web request

This procedure is only for `$gptweb` and `$claudeweb`. It installs or reuses their standalone Git marketplace helper and connects the exact Web tab that supplied the copied request. It does not install an AI plugin or require Codex CLI. It does not use browser control, Chrome debugger access, a browser extension installer, an Initiate Bridge button, or a Snap listener.

The copied request must include its UUID. If it is absent, explain once that the user must copy the command from the intended CogentSpec Web work area's existing command button. Do not inspect tabs to discover a replacement, choose a running workspace, or manufacture a request.

1. Check whether the host exposes a supported local Windows execution tool. A Linux shell and browser access do not supply it. If the tool exists but needs permission, use its actual approval flow and wait. If it is absent, say that this AI session needs a connection to the user's Windows execution environment before the install command can run. Do not invent an approval request, change host settings, run on Linux, or attempt a browser workaround.
2. Using that Windows tool, fetch `https://cogentspec.app/api/bridge/web/v1/release` over HTTPS. Require protocol `cogentspec-web-release-v1`, repository `https://github.com/cogentspec/cogentspec-marketplace.git`, a 40-character lowercase hexadecimal revision, 64-character hexadecimal manifest and bootstrap hashes, and commands exactly `$gptweb` and `$claudeweb`. Its revision must match the pinned Git revision from which these instructions were read; if a release changed meanwhile, explain that a fresh command must be copied rather than silently changing procedures.
3. Download `web-bridge/v1/bootstrap.ps1` from that exact revision of the official Git repository, through `https://raw.githubusercontent.com/cogentspec/cogentspec-marketplace/<revision>/web-bridge/v1/bootstrap.ps1`. Verify its SHA-256 against `bootstrapSha256` before executing it. Keep the downloaded script in a local temporary file; do not install a skill package or invoke a plugin manager. Run that verified script once with `-RequestId <copied UUID> -Command '$gptweb'` or `-Command '$claudeweb'`, plus `-Revision <revision> -ManifestSha256 <manifestSha256>`. Use the installing Windows user's permitted execution scope. The bounded helper verifies every runtime file, preserves the existing account credential, starts its own hidden Web worker, and waits for the page's fresh acknowledgement.
4. The existing page performs the protected handoff itself. Do not inspect, click, navigate, reload, open or rearrange browser tabs/windows. Do not ask the user to approve ownership in this AI chat. Account/device authorization is a real prerequisite: report the helper's bounded message if a computer needs its first account authorization. Do not approve it automatically, copy protected credentials or substitute another installation.
5. Report connected only when the helper returns protocol `cogentspec-web-command-v1`, status `connected`, `workspaceConnected:true`, `acknowledgementVerified:true`, `browserOpened:false` and `browserControlled:false`. Otherwise report its safe `userMessage` and stop. Do not retry, generate a different request, or claim success from an installed helper or ready worker alone.

Keep request metadata, Windows credential material and project context private. A request identifier is not a Windows execution permission or an account credential. Other connector types do not use this protocol.
