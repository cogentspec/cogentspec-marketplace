# Open CogentSpec beside the GPT Desktop conversation

Read `../cogentspec/SKILL.md` and follow its update, project-context, privacy, account, and connection requirements for **Connect the current AI project**, with these destination-specific changes only:

1. Invoke `../cogentspec/scripts/start-cogentstack-bridge.ps1 -ContextKey <resolved context> -Surface chatgpt -Experience desktop-ui` exactly once.
2. Require the normal ready contract and require `workspaceUrl` to be the private `chatgptWorkspaceUrl` with `experience=desktop-ui`. Do not expose either private URL in commentary or logs. Preserve the launcher's exact-conversation confirmation independently of layout.
3. Call `mcp__codex_app__open_in_codex` exactly once with `target: { type: "browser", url: workspaceUrl }` and `placement: "right"`. Omit `threadId` and `tabId`. Treat `opened` or `queued` as acceptance of the open request, not proof of a native two-column conversation/workspace split. Do not retry the native open or render another destination after acceptance.
4. After acceptance, where host automation is permitted, run `py -3 ../cogentspec/scripts/ensure-codex-sidebar-hidden.py --experience desktop-ui --ensure-split --timeout-ms 3000` exactly once on Windows. Run it AFTER the native open, because opening the tab can change the host layout. Read its one-line JSON. It targets one unambiguous accessible host window. For sidebar hiding, restore the state-aware Windows method: require a visible, enabled `Hide sidebar` control, the same window in the foreground, and no shortcut keys held; recheck state and foreground immediately before sending `Ctrl+Shift+S` once. An already-hidden or uncertain sidebar receives no input. Do not require InvokePattern for this sidebar action: the host can expose the button without that pattern. Verify `Show sidebar` afterwards; accepted input alone is not success. Split restoration remains independent and invokes `Enter split view`, `Exit full view`, or `Show tabs` only from a fresh non-split state. It changes no window geometry, steals no focus, and does not cycle layouts blindly. Respect host automation restrictions; do not use the helper to bypass a prohibited Computer Use action.
5. The helper must attempt sidebar hiding and split restoration independently in the same uniquely selected window. A sidebar failure must not skip split restoration. Read `sidebarResult` and `splitResult` separately; the control diagnostics include the failed stage, bounded reason, and Windows HRESULT when available. Never infer unsupported controls from a generic failure or introduce an unverified fallback. Require `status: layout_verified`, `layoutVerified: true`, `sidebarState: hidden`, and `workspaceLayout: split` before describing the Desk layout as verified. A green LED, ready Bridge, or accepted/queued open is NOT layout evidence. If Python or host verification is unavailable, or the helper returns `unavailable`, `ambiguous`, or `failed`, report the data connection and unverified layout separately. Do not claim that the conversation is visible beside the page or that the sidebar is hidden. State the helper's bounded reason; do not restart the Bridge or substitute Popout/Web.
6. Say **CogentSpec is connected beside this GPT conversation, with the main sidebar hidden.** only when BOTH the normal current-conversation connection gate and the Desk layout verification succeed. A layout failure must be reported as a partial Desk result even when the data connection is ready. If native opening itself is unavailable, return the independent `webWorkspaceUrl` once as `[Open CogentSpec workspace](<URL>)` and explain that the Desktop split view could not be opened automatically.

This command selects only the compact GPT Desktop UI route. Its layout helper must not run for Popout, Web, Claude, or the generic connection. It must not activate Popout layout, resize windows, change shared host preferences, or alter the shared project flow. Never send `Ctrl+Shift+S` or `Ctrl+Shift+B` as a blind toggle. If automation is prohibited or the host controls cannot be verified, retain the partial result and request a user-observed layout check rather than claiming success.

For an explicitly requested diagnosis, where host inspection is permitted, `py -3 ../cogentspec/scripts/ensure-codex-sidebar-hidden.py --experience desktop-ui --inspect-only --timeout-ms 3000` reads layout state and control-pattern availability without invoking controls or sending input. It returns `readOnly: true` and `inputSent: false`; inspection alone is not a repaired layout. Do not use this mode to bypass host inspection restrictions, and do not publish a repair based only on simulated controls.
